# Provider documentation

Before looking up provider documentation remotely, check `api-docs/` for
downloaded official documentation. Use the local copy when it covers the
question. Look up official sources remotely only when the relevant material
is missing from `api-docs/`.

# Live provider tests

The standing budget per work session is about 5,000 Scrapfly credits and
1,000 Serper searches. Ask before exceeding either budget. Track actual provider
usage where available and keep normal runtime per-request cost limits unless
live evidence justifies a change.
